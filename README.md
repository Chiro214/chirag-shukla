# Chirag Shukla — Portfolio

Personal portfolio website of **Chirag Shukla**, Full-Stack Developer & AI Systems Engineer based in Mumbai, India.

Built with semantic HTML5, modern CSS3, and vanilla JavaScript with zero framework overhead.

## Highlights
- **Interactive 3D Technology Globe:** 65+ self-hosted technology nodes in orbit with drag rotation, inertia, and depth perspective.
- **Hero Flow Canvas:** Interactive canvas particle flow-field reacting to pointer movement and scroll depth.
- **Selected Work:** Production systems spanning healthcare infrastructure (ABDM), enterprise SaaS, applied AI/automation, quantitative trading, and Web3 marketplaces.
- **Capabilities Matrix:** Languages, Frontend, Backend, Databases, AI/ML, Cloud/DevOps, and Data Engineering.

## Tech Stack
- HTML5, CSS3, Vanilla JavaScript
- Custom `@layer od-layout` structure primitives
- Self-hosted SVG vector icon library
